# data/processed/daily_counts — wide daily activity matrix

Generated by [`src/build_daily_counts.py`](../../../src/build_daily_counts.py) from
`data/raw/ML_bat_repstat/yearly/`. One CSV per logger *sit* threshold (gap in seconds that
defines an independent visit event):

| file | gap threshold |
|------|---------------|
| `daily_counts_sit10s.csv`  | 10 s (finest, near-raw chattering) |
| `daily_counts_sit30s.csv`  | 30 s |
| `daily_counts_sit60s.csv`  | 60 s |
| `daily_counts_sit120s.csv` | 120 s |
| `daily_counts_sit300s.csv` | 300 s |
| `daily_counts_sit600s.csv` | 600 s (coarsest, ~one event per emergence) |

## Layout

```
Year, Bat Id, Colonie, Day1, Day2, ..., Day365, Lactating
```

* one row = one bat in one year (2,070 rows per file)
* `Bat Id` = activity tag id, upper-cased and zero-padded to 10 hex chars
* `Colonie` ∈ {BS, GB2, UA}
* `DayN` = number of independent visit events registered in **bat-day N**, where a bat-day
  runs **12:00 → 12:00** of the next human day. `Day1` = Jan 1 12:00 → Jan 2 12:00.
  29 February is dropped, so the table is always 365 columns wide (day index tracks the
  calendar date, not day-of-year).
* `Lactating` = `Reproduction State` from `yearly_table_L_Mbec.xlsx` (Yes / No / empty),
  joined by `ID4`. Empty = not labelled (either no table row that year, or the table's own
  field is blank).

## Caveats

* **Junk tag ids dropped**: reader error codes (`FFFFFFFFFF` alone is 7,243 rows,
  `EEEEEEEEEE`, `9999999999`) and sub-4-char truncated reads. 7-digit tags are zero-padded
  and *merged* into their 10-char counterparts.
* **Year edge**: a detection whose bat-day falls outside the file's calendar year (i.e. on
  Dec 31 after 12:00, or Jan 1 before 12:00) is dropped — ~0.09 % of rows.
* **Multi-colony movers**: 68 (year, tag) combos are detected at more than one colony in
  the same year. Counts are summed into one row; `Colonie` comes from the label table when
  the bat is labelled, otherwise from the folder with the most detections.
* **Unresolvable labels**: 4 `ID4`s (`0832`, `9900`, `AA3C`, `F44A`) are last-4-digit
  collisions between two different tags — left unlabelled rather than guessed.
* **Not included**: 123 labelled bat-years inside 2008–2024 have no activity at all; they
  are absent from these tables (absence of rows ≠ zero detections).
* Two colony-years are absent from `yearly/` (49 of 51 present) and contribute no rows:
  **2008/UA** and **2023/BS**.
